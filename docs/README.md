# docs/

This directory is the shared source of truth for **anyone working on this
repo — human or AI agent**. If you're picking up work here for the first
time, read in this order:

1. **[ARCHITECTURE.md](./ARCHITECTURE.md)** — what the app does, how the
   pieces fit together, and where state/data flows.
2. **[CONVENTIONS.md](./CONVENTIONS.md)** — the coding, styling, and file
   organization rules to follow when adding or changing code.
3. **[REFINEMENT_PLAN.md](./REFINEMENT_PLAN.md)** — the current backlog of
   refinements, broken into independently shippable phases with concrete
   file targets and acceptance criteria. Check here before starting new
   work to avoid duplicating or conflicting with an in-progress phase.

## Keeping this up to date

- If you complete a phase (or part of one) in `REFINEMENT_PLAN.md`, mark it
  done and note what changed before ending your session.
- If you change the app's structure (new top-level directory, new state
  slice, new external dependency), update `ARCHITECTURE.md` in the same
  change — don't let it drift.
- These are hand-authored docs. The `<!-- graft:start -->…<!-- graft:end -->`
  block in `../AGENTS.md` is managed automatically by the `graft` tool —
  never hand-edit it; it's regenerated by `graft build`.

## Repo-level pointers

- `../AGENTS.md` — tool-managed `graft` context block; use `graft ask`,
  `graft skeleton`, `graft callers` etc. to navigate code instead of
  grepping, per the instructions there.
- `../README.md` — human-facing quick start (run, build, env vars).
